# 🇹🇭 Thai Personal Income Tax Calculator

An interactive web application designed to help users estimate their annual personal income tax in Thailand. This project focuses on implementing progressive tax logic and providing a clean, user-friendly interface.

## ✨ Features
* **Automated Calculation:** Instantly calculates total annual income including bonuses.
* **Tax Deductions:** Automatically applies standard personal deductions and expenses.
* **Progressive Tax Logic:** Accurately calculates tax across multiple brackets (0%, 5%, 10%, and more).
* **Real-time Feedback:** Uses color-coded alerts (Success/Error) to display tax liability.

## 🛠️ Tech Stack
* **Language:** Python
* **Framework:** Streamlit (for the Web Interface)

## 🚀 How to Run
1. Clone the repository
2. Install Streamlit: `pip install streamlit`
3. Run the app: `streamlit run app.py`
